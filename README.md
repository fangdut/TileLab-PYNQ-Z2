# TileLab FPGA 瓷砖表面缺陷停驻检测

面向固定花色与输入条件的单片瓷砖硬件筛查、区域提示和可追溯复检原型。当前用公开实拍照片回放；视觉计算全部在PYNQ-Z2的PL，电脑与ARM负责输入、通信、控制、显示和记录。

**当前交付：工程V202，技术报告V205，视频准备材料V203，海报V204。** V205仅整理报告和仓库文档，未改变RTL、模型、固件、阈值或启动器，未进行新的上板测试。初级赛道按官方Word五部分模板组织报告；具身智能赛道截图仅作为内容完善参考。

## 运行时分工

| 部分 | 实际职责 |
|---|---|
| 电脑 | PNG/JPEG解码、RGB打包、传输、显示、复核、审计 |
| ARM PS | 网络、CRC完整性、任务控制与状态 |
| FPGA PL | 原图缩放至224×224、定点归一化、INT8 MobileNetV2特征、投影、良品参照距离、报警、28×28网格及原图掩膜 |

运行时视觉推理不使用PC/GPU/ARM。系统管理仍包含软件；卷积累加为INT32，部分后处理使用更宽整数。47步任务图复用计算单元，不是所有层完全展开。

## 冻结实测

| 指标 | V202结果 | 范围 |
|---|---|---|
| 开发图复现 | 117张，分数/掩膜/元数据逐值一致，序号除外 | 反复参与开发的公开照片 |
| 图像报警 | 33正常零误报，84缺陷检出 | 不是独立测试准确率 |
| PL内核均时 | 124.72 ms | 117图 |
| 传图加检测均时 | 501.79 ms | 不含解码、完整UI复核与保存 |
| 逻辑闭环 | 100周期，50放行/50隔离，均时1.220 s | 含0.25 s脚本复核等待；无机械动作 |
| 接口验收 | 22次实板回放，38次不安全动作被阻止 | 自动脚本复核 |
| 时钟与资源 | PS FCLK_CLK0 100MHz；DSP 218/220；BRAM 127.5/140 | setup +0.013ns、hold +0.024ns、DRC 0 |

201次固定DDR帧微基准约8.02内核fps，不能当作连续新视频端到端帧率。换线后整轮约310秒通过，不是全天长稳或电气根因证明。未知花色、独立实物批次、精细裂纹分割、功耗和CPU/GPU加速比尚未验收。

## 从哪里开始复现

有随附V202工程包时，先校验哈希并按[工程包复现步骤](docs/reproduction.md)部署。GitHub保存源码、冻结基线和证据；本地V202完整ZIP不是已发布的GitHub下载资产。仅克隆仓库不能假定获得该ZIP，也不要用旧V179打包命令冒充V202闭环包。

仓库保留已有源码目录，新增文档和指标入口，不搬动工程文件。[旧版首页与历史实验记录](README_HISTORY_V203.md)保留原始叙述，但其中“当前”、FPS和候选状态均属于当时记录；当前口径以本页、V202原始证据和V205报告为准。
