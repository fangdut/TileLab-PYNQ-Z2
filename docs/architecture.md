# 计算与控制分工

电脑在瓷砖到达截图点时冻结native canvas帧，逐像素核对源照片，解码并打包RGB，经以太网交给PS和PL。PL完成缩放至224×224、定点归一化、47步整数特征图、投影、参照距离、判定和原尺寸粗异常掩膜。PS只承担通信、CRC、DDR和任务控制。

电脑按工件编号/截图/模型/启动身份/帧号接收结果，把PL区域涂为红色并显示。照片继续行进，未报警且校验有效时自动通过；报警或结果未到在右侧停止。自动通过是电脑控制策略，不把软件状态机称为PL实现。人工确认方式仅会话一次，报警意见逐件记录。

电脑GPU可能渲染浏览器，未用于运行时模型推理。HDMI是电脑到外屏的显示链路，当前不从板卡HDMI取帧，也不在板端叠加红色区域。板卡HDMI模块保留不会自动提高网口检测吞吐。

卷积权重/激活INT8、累加INT32，投影和距离按需要使用更宽位宽；计算单元复用而非所有网络层完全展开。软件也能完成相同功能，尚无同口径性能功耗对比，不宣称不可替代或固定倍数加速。
