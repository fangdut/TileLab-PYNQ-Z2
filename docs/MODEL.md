# 冻结模型与参照

运行使用整数MobileNetV2特征（features 0–13）、PCA64投影及1024个良品参照码字，内部输入224×224，输出28×28异常网格并映射到原图。模型选择服务于XC7Z020资源预算，不是新网络发明。

当前主纹理模型751760字节，SHA256 `1501e32e733b566e17d125613d0989c04291b658459d63b826e418f6f713ed65`，CRC32 `2781797194`。模型ABI、冻结协议和来源见[模型目录](../project/pynq_z2_tile_v1_53/models/texture_v170_r1/README.md)。该目录的早期HLS11速度为历史记录，V202速度以metrics为准。

卷积权重和激活INT8、卷积累加INT32；投影和码本为INT16，距离及其他后处理使用所需位宽。不能把全部数据描述为INT8。47步任务图复用计算单元，CPU/GPU/ARM不承担运行时视觉推理。

V200固件绑定纹理砖和实验陶瓦两套已有参照；切换不更换BIT，但不代表任意花色在线学习。至少3不同良品+1已知缺陷的核验只检查已部署参照在本批条件是否适用，不训练CNN，也不构成独立精度认证。

离线拟合工具及数据协议在`tools/fpga_texture_v170/REFERENCE_CALIBRATION.md`及模型目录。新材质必须冻结参照、阈值和独立验证协议。开发集已反复用于方案选择，117图结果仅作为开发复现证据。
