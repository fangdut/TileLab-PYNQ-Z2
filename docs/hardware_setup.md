# 硬件接线与环境

复现目标是Windows电脑与PYNQ-Z2（XC7Z020）之间的原图停驻检测。当前没有相机、固定光源、传送带、到位传感器或剔除执行器。

| 项目 | 设置或用途 |
|---|---|
| 开发板供电 | 按PYNQ-Z2板卡手册选择供电来源及对应跳线，确认可靠供电；本项目不补造未记录的电气测量 |
| USB数据线 | 电脑连接板卡JTAG接口，安装板卡USB/JTAG驱动；不可使用仅充电线 |
| Ethernet | 电脑连接板卡网口，板端192.168.33.10，电脑同网段且地址不同，例如192.168.33.1/24 |
| 启动模式 | 与JTAG易失下载兼容；下载BIT及ELF，不写Flash |
| HDMI | 当前网口停驻复现不需要；不要同时运行另一HDMI控制作业 |
| 开发工具 | Vivado/Vitis 2025.2及可调用的XSDB |
| Python | 3.12；NumPy、Pillow，按工程包requirements.txt安装 |

`TILELAB_PYTHON`指向实际Python解释器；`TILELAB_XSDB`指向实际XSDB，适用于安装路径与原机器不同的情况。以工程包脚本为准，不照搬开发机器的D盘环境。

工程包根目录的`启动检测.cmd`会先做文件与配对核验，再易失下载并启动工作站。重复服务和同板多控制器会干扰结果身份；按[复现步骤](reproduction.md)使用单一工作站。停止时先完成当前工件，再运行`停止工作站.cmd`，保留runtime审计。

真实整机正面、斜45度、开发板接口及连线照片仍由参赛者补齐。报告现有位置是明确预留，不能将公开板卡照片或生成图当作本项目实拍。换USB线后有限复测通过，但没有电压/电流实测，也未唯一确定此前POR根因。
