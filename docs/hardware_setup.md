# 接线与环境

|连接|本版用途|
|---|---|
|电脑与PYNQ-Z2网口|发送原生截图RGB、模型配置和控制，返回PL结果与身份|
|电脑与板卡Micro USB PROG UART|JTAG下载/调试、可选UART；是否供电由板卡电源跳线决定|
|电脑HDMI与显示器|直接显示电脑渲染的流水线，与电脑复核页用扩展模式|
|板卡HDMI IN/OUT|BIT内保留但当前检测不使用，不必串接显示器|

平台XC7Z020；PS FCLK_CLK0 100MHz。需可靠供电、真实USB数据线、板卡驱动、Vivado/Vitis2025.2、Python与NumPy/Pillow及Chrome。板端192.168.33.10，电脑同网段不同地址。没有实体相机、光源、机械输送或剔除执行器。换线后的有限复测不证明电气根因或全天稳定。

先校验完整工程，再按[复现](reproduction.md)从启动流水线.cmd进入。原停驻工作站保留用于工位核验。不要同时开启旧HDMI推理控制作业。
