HLS39 interleaves the 64 projection outputs through the same eight projection multipliers, replacing repeated 16-step pipeline startup with one 1,024-iteration pipeline. Signed32 partial sums cover the full signed8/signed16 domain, while signed64 bias and final rounding remain exact. All 117 original-photo C scores/masks and the odd-row fixture match. The loop achieves II=1, iteration latency 9, recurrence distance 64. HLS estimates 219 DSP/251 BRAM18. Both reduced nine-task RTL launches pass in 602,800/602,808 cycles versus HLS38's 665,600/665,608 on the identical 79x65/internal-side-80 fixture. This 9.44% cycle reduction is not a measured full 47-task production detector speed. Complete HLS39 HDMI hardware is building as HW04; it has not been programmed.

The centered packed kernel requires encoder weights in [-127,127]. Its exhaustive mathematical check covers 16,646,400 activation/weight triples. Build preflight checks every convolution weight against the actual binary model and graph descriptors (529,760 bytes, zero -128 values), and proves active signed24 accumulators (8,052 active channels, 12 zero-multiplier channels). Negative checks reject both an injected -128 weight and an excessive active bias. Zero-multiplier channels produce exactly zero despite unused accumulator wrap. The earlier general INT8 arithmetic primitive also covers -128, with all 16,777,216 triples checked, and remains separately documented.
