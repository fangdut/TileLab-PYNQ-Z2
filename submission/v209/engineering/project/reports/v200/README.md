# V200 标定 检测 复核操作说明

本版把已部署参照的工位核验与检测、人工复核、处置记录连接起来。支持纹理瓷砖参照和陶瓦实验参照；不自动学习任意花色，不在线训练CNN，也不把4张核验图当作独立准确率认证。

## 启动与停止

开发板连接USB数据线和网线，板端192.168.33.10，电脑网口192.168.33网段。双击“启动检测.cmd”，校验文件后进行易失下载、加载默认参照并打开http://127.0.0.1:8793/。需要Python、requirements.txt、Vivado/Vitis2025.2和板卡USB驱动；TILELAB_PYTHON及TILELAB_XSDB可覆盖路径。

双击“停止工作站.cmd”只停止本目录的空闲服务，不断电、不删记录；当前工件未完成时拒绝停止。切换到旧工程前，先用当前工程的停止脚本结束服务，再进入保留的V199目录启动。不要同时使用其他程序控制同一开发板。

## 1 建立材质与标定核验

填写操作员、材质／花色名称和真实输入条件，选择对应的已部署冻结参照。照片回放应明确填写数据来源及“照片回放”，不能冒充现场相机或光照标定。选择已有材质同样会核对板端参照，并使上一工件结果失效。

在“本次用途”选择“良品核验”，依次处理至少3张不同的良品；再选择“已知缺陷核验”，处理至少1张已知缺陷。每张都执行：载入固定输入 → 确认输入保持 → FPGA检测 → 根据实际样本填写复核结论 → 记录人工复核 → 勾选处置确认 → 完成并记录该核验样本。

同一图片不能重复凑数量或同时充当良品和缺陷；有任何不一致不能封存。需排查拍摄条件、参照适配性或样本标签，失败记录保留。不能只抬高阈值或忽略失败样本把配置变成已验证。

确认输入条件与记录一致后封存本批核验。凭证绑定材质、参照SHA、启动编号、核验批次和样本结果。换花色或位置／光照变化，应新建材质记录；同一条件重新核验会建立新批次，保留旧凭证与失败记录。

## 2 正式检测与人工复核

选择“正式检测”，确认条件一致，载入原图并固定，再启动FPGA。图片宽高均不超过1024，工作站不自动缩放原始输入。显示的是PL原始判定与粗异常区域，不是精确裂纹轮廓。

FPGA返回后必须记录人工复核。FPGA正常、人工正常且核验有效时，才可再确认逻辑良品放行；缺陷可隔离；待定需要说明并移出；人工正常但FPGA报警不能覆盖成良品放行。生产复核冲突会使当前核验失效，需排查后重新核验。外部换参照、设备重启、源图或结果证据变化均使旧结果不可继续处置。

## 3 追溯与验收边界

页面提供CSV和JSON导出，包含材质、批次、凭证、原图／模型指纹、帧序号、操作员、复核及处置。记录在runtime下保留。服务重启不会恢复旧工件结果；开发板启动编号改变后必须重新核验。

源码控制测试32项通过；真实板端API回放22次、浏览器回放2次，均由明确标识的自动化操作员驱动，不代表真实人员逐图复核。117张停驻节奏回归逐值一致，逐图间隔1秒、批次199.17秒，不能据此宣称连续高负载稳定性。另一次无额外间隔批次在39张后遇到连接重置／DDR复位，根因未确定，日志保留。此版形成闭环功能，不宣称所有稳定性风险已消除。

图像运算仍全部在FPGA；ARM及电脑负责传输、校验、配置与记录。没有实体相机、输送电机或剔除执行器。本包不是比赛网站已提交版本。
