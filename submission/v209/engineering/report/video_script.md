# TileLab发言稿：正常不停，异常复核

建议约2分30秒至2分50秒。画面提示不用念；检测和移动保持原速。

【设备全景】

大家好，我们的作品叫TileLab，是一个用于瓷砖表面缺陷筛查的原型系统。

我们最初想做的，是一条自动检测流水线：瓷砖不断送进来，系统先找出疑似裂纹，让人集中复核有问题的瓷砖。

【单张检测结果，随后切到流水线】

为了实现这个想法，我们先从单张照片开始。先让FPGA完成检测，再围绕误报、漏检和稳定性持续调试。等这条链路跑通以后，我们把它接进了现在的模拟流水线。

这里使用的是真实瓷砖的公开照片，裂纹本来就在照片里。电脑负责模拟输送、截图和显示，图片经网口送入开发板，图像检测由FPGA完成。

【正常图01、02依次入线，完整拍到继续通过】

现在看第一块瓷砖。它进入左边检测区时，系统就截取一帧交给FPGA，瓷砖继续匀速向前走。

这张没有报警，系统自动通过。后面这张也没有报警，同样继续通过，不需要每一张都停下来点击确认。

我们给检测区留出了处理时间。如果到了右边还没有有效结果，它会停下来等待，不会把没有结果当成正常。

【裂纹图03在移动中出现标记，到右侧停下】

接下来是一张有裂纹的照片。FPGA返回了缺陷提示，在这块瓷砖上显示红色异常区域，让它走到右侧复核区后停下。

红色区域帮助我们找到疑似问题，是粗略的异常提示，不是精确的裂纹轮廓。

【本人查看原图与标记，首次确认复核方式，再点“确认缺陷”】

我查看后确认这里确实有裂纹，记录为缺陷，系统再将它标记为隔离。后续异常图只需要直接填写复核结论，复核方式不用反复勾选。

【操作记录，再回到设备全景】

系统会分别保存自动通过和人工复核的记录，把每次截图、FPGA结果和工件编号对应起来，方便追溯。

这样，我们就把单张照片检测，扩展成了匀速入线、自动检测、异常停驻和人工复核的完整流程。下一步会验证更多独立样本和现场条件，为接入真实相机和输送设备做准备。谢谢大家。

## 操作与用词

选择01/02/03，检测区4秒，启动队列。正常图不点复核；异常到右侧后由本人实际查看、记录。首次确认复核方式，后续不用重复勾。当前若有未完成工件，先处理它。

联调视频约40秒，带“自动回放、非人工”字幕，不能说成本人完成的复核。设备全景另行实拍。为控制时长可节选重复过程，但不剪掉检测等待以暗示更快速度。

“准确率提高”需有同条件改进前后数据；本次新增的是流程与自动通过策略。“自动通过”表示当前配置未报警，不能直接称工业质量合格。4秒是检测区预留时间，不能说成FPGA计算耗时。
