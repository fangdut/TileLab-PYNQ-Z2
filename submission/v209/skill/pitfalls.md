# 失败观察与定位流程

|触发条件|观察|排查步骤|接受条件与边界|
|---|---|---|---|
|更换模型、重启板卡或旧网页仍开着|旧结果可能误配当前工件|核对会话、工件、输入SHA256、模型和启动身份，失配后撤销结果|当前结果与当前输入、身份一致；无结果不得当正常|
|修改BIT后仍使用旧XSA/ELF|表面连接成功不能证明部署配对|先verify_files，再核对BUILD_RESULT与XSA内嵌BIT，再做板端数值比对|文件相等不代替功能及时序验收|
|显示链路改变颜色或canvas尺寸|原图与实际送检像素可能不同|冻结原生像素截图并逐值核对，不用缩略图替代输入|只比较实际输入域；新成像条件重新核验|
|本机HTTP状态查询暂时超时|录制期间出现Win10060，后端仍保留结果|只对幂等状态读取有限重试；上传、推理、复核和处置不盲重发|不能仅据一次恢复确定原故障根因，不能宣称全天长稳|
|外层CAD命令成功而内部Tcl失败|日志标记与退出码不一致|保留内部日志、核对唯一成功标记和产物指纹|未完成实现/板测不得发布为通过|

原始记录位于工程恢复目录project/reports/及顶层report/communication_incident.md。该清单可用于其他FPGA/嵌入式工程；目标协议、DMA所有权和物理联锁仍须按设备独立实现。
