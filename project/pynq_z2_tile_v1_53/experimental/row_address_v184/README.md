# V184 图像行地址位宽与流水线实验

目标来自 V182 的真实布线报告：125 MHz 一次修复后，最差路径为 HLS 状态机至图像行地址 22×32 位乘法的 DSP 级联输入，建立时间仍缺 0.187 ns。当前已验收版本仍为 V179，实测 HDMI 连续处理 8.16955 次/秒。

本实验将通过原始输入合法性检查后的 `y0 * width`、`y1 * width` 改为共享的 10×11 位无符号乘法，显式绑定 DSP 并设置三拍运算延迟。保留模型、分辨率、阈值、原始非法尺寸拒绝规则及所有数值计算。

独立的原始整数缩放公式遍历 side=8..224、height=1..1024 的全部行，共 25,776,128 组，确认两条采样行均在合法范围内。实际 HLS `row_offset` 函数遍历 row=0..1023、width=1..1024 的 1,048,576 组输入，与未截断整数乘法逐一相等；最大偏移为 1,047,552。实际缩放公式达到的最大行号为 1022，严格小于可表示上限 1023。初版检查器错误要求实际最大值必须等于上限，后已修正为范围检查并在全新输出目录通过。

运行范围检查：

```powershell
python experimental/row_address_v184/check_bounds.py --out D:/Vivado/TileLab_RealPhotos_20261020/v184_bounds_fresh
```

输出目录必须不存在。该检查使用电脑上的原生 C++，仅证明范围和整数一致性，不代表 FPGA 上的速度或 RTL 正确性。完整 117 张照片回归、生成 RTL 检查、RTL 联合仿真、整机时序及上板持续检测仍需逐项通过；HLS 估计不能替代实测。
