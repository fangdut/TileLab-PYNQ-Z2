# 正常纹理分组可行性实验

以16个亮度直方图统计与3个横向差分能量为描述，按正常样本进行确定性分组和
阈值标定。它不是作者花色编号，也不能当成工厂SKU标定。没有CNN训练。

从256张正常记忆、320张正常标定形成8组L1参照后，先冻结参数再打开80个新
文件。离线结果TP37/40、FP3/40；同一批输入的原线状分支为TP38/40、FP4/40。
总体正确数都74/80，少1误报同时多1漏检，不能认定无条件优于原方案。
扩大样本前的某些组因正常标定不足返回unknown，unknown不计为判对。

窄线门控与差分幅度限幅均加剧漏检，失败结果保留。不进入正式工作站。
全部图片现在是公开开发结果，不能继续调参后仍称独立盲测。实体工件独立性
未建立，原扫描条带也不等于整片瓷砖。照片与参考二进制仅本地研究保存。

reference.py与research/是离线工具；当前没有分组器的完整FPGA实现。
