# V187：共享 DSP 的精确双路乘法实验

这是独立算术实验，**尚未接入检测器、没有整机布局布线或实板吞吐结果**。当前已验收版本仍为 V179，连续 HDMI 实测 8.16955 FPS。并行在做的 V186 缓存分离版正在整机实现。

目标是在卷积中，让同一激活值对应的两路有符号 8 位权重共用一次乘法；最近邻模式仍计算完整 17 位差值的平方，不降低精度。DSP packing 已有公开研究，本实验不把这一通用方法宣称为原创。

对于有符号 8 位 `a,w0,w1`：

```
packed = 65536*w1 + w0
P = a*packed
p0 = signed16(P[15:0])
p1 = signed16(P[31:16]) + (p0 < 0)
```

负低位乘积会向高位借位，必须补回。`packed` 的实际范围是 −8,388,736 至 8,323,199，使用有符号 25 位；乘法另一端使用 18 位。切换最近邻模式时，两端输入为符号扩展后的 17 位差值，保留低 34 位精确平方。

已完成的证据：

- 独立 C++ 穷举全部 16,777,216 个三元组、131,071 个合法最近邻差值，全部一致；删除借位修正会出现 8,323,072 个错误。
- 三个使能时钟阶段的 RTL：614,312 个输出检查、38,802 个停顿周期、126 次有效复位清空；乘法参考直接计算两路乘积及差值平方。
- 针对 `xc7z020clg400-1` 的独立综合：实际 1 个 DSP48E1、45 LUT、54 寄存器、0 BRAM。这不是整个检测器的资源结果，综合时序也不能替代整机布线验收。

复现（每次指定不存在的输出目录）：

```powershell

python test_rtl.py --out D:/TileBuild/packed_rtl01
python synthesize_unit.py --out D:/TileBuild/packed_synth01
```

本地验证需要 Vivado/Vitis 2025.2；脚本沿用本机安装路径 `D:/2025.2`。原始记录见 `../../reports/v187/`。
