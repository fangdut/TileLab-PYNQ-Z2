# Local research protocol sources

These scripts preserve the original experiments, including failures and path-based
selection rules. Their historical paths point to the local research workspace.
They are not the station runtime and do not execute CPU detection during deployment.
Do not train or tune again on the exposed new40 and call it an independent holdout.
HFENet photos, masks, raw per-column statistics, and fitted data-derived binaries
are intentionally absent. Use the author-linked archive only within its terms;
repository code MIT is not assumed to license dataset redistribution.
