# 原生横向像素线状分支实验

这是尚未接入正式检测器的HLS单元，不能替代已上板主检测器。
输入应由PL预处理器提供224个采样行，保留每行全部原生列，灰度为`(R+2G+B)//4`。
当前Python/C++读图及采样只用于离线校准和验证，没有装入工作站的运行路径。

对水平跨度2、4、8，计算`r=2Y[x]-Y[x-d]-Y[x+d]`，沿采样行累加
有符号和N、绝对值和E。`floor(N²/(E+1)) > T`由`N² >= (T+1)(E+1)`精确实现，
不需要硬件除法。阈值来自64张良品标定图，冻结后再测另外的文件。
该分支针对近竖直打印细线，不覆盖任意走向裂纹。

N用18位有符号、E用17位无符号。每行像素0..255，`|r|<=510`，224行给出
`|N|,E<=114240`，乘积36位安全。35位统计量加1位判定打包为64位输出。
HLS独立单元估计2DSP、10BRAM18、4882LUT；这是独立综合估计，不能当作整机
资源增量或已实现时序。RTL三个事务检查精确统计、下一帧清零和非法宽度拒绝。

源数据为作者HFENet公开工业扫描条带，256×1408，按预先固定规则取一个256×704
像素片段，不缩放、不添加缺陷。同名文件不等于同一实体，实体独立性未建立。
作者仓库软件MIT并不自动成为独立数据集的再分发许可，本项目不随包分发这些照片。

已公开开发40图：18/20缺陷、1/20良品误报。随后冻结参数的新文件40图：
16/20缺陷、3/20良品误报，16张命中的列与作者缺陷列相交。
因此判定质量没有通过，不晋升为正式分支。40张整数统计与独立NumPy参考一致
只证明实现计算正确，不等于检测准确率通过。
