# V185 特征插值流水线实验

V183 的 125 MHz 实现初始建立时间为 −0.342 ns。实际关键路径从列坐标的一位经过特征插值的 11 级组合逻辑、7 个 CARRY4 到结果寄存器。一次物理修复后仍为 −0.015 ns，因此未下载；已验收固件仍为 V179，连续 HDMI 实测 8.16955 次/秒。

本版保留 V184 的窄位宽图像行地址乘法，将原来内联的横向、纵向四分之一像素插值拆成各两拍、II=1 的独立 HLS 模块。保留全部加减和移位运算、最终有符号舍入规则、模型、分辨率及报警阈值。生成结构包含 16 个横向模块和 16 个纵向模块，模块本身不使用 DSP。完整 HLS68 估计为 213 DSP、251 BRAM18、70,949 LUT、70,171 FF；这些不是实际 FPGA 使用量。

当前证据包括：

- 117 张真实照片的完整 C 输出文件与已验收 V179 逐字节相等；这是开发集回归，不是独立盲测。
- 实际生成 RTL 的横向单元遍历全部 262,144 组有符号 8 位输入和四种权重，纵向单元检查 131,088 组边界与随机值，使用独立的加权和公式作对照。
- 生成模块的端口位宽、两拍延迟、II=1、16 路实例和零新增 DSP 均有检查，六种结构破坏测试被拒绝。行地址函数及非法尺寸检查与 V184 的穷举版本字节一致，并重新检查了生成的行地址结构。

单元仿真入口：

```powershell
python experimental/quarter_pipeline_v185/test_quarter_rtl.py --hls D:/Vivado/TileLab_RealPhotos_20261020/v170_hls68 --out D:/Vivado/TileLab_RealPhotos_20261020/v185_quarter_unit_fresh
```

输出目录必须不存在。HLS69 与 HLS68 源文件一致，用于完整检测器的两次缩小配置 RTL 联合仿真及 IP 导出；通过后仍需整机时序、DRC、FIFO Gray 总线偏斜检查、直接 117 张数值核对和真实 HDMI 持续测速。没有上述实板证据前，不能把本实验描述为达到 10 次/秒或已验收版本。
