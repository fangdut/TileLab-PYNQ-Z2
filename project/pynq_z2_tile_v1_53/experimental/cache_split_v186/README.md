# V186 预处理与卷积行缓存分离

V185 的 125 MHz 整机实现未通过：建立时间 −0.786 ns，保持时间 +0.050 ns，DRC 为零，实际使用 218 DSP。关键路径由卷积循环初始化寄存器经过共享行缓存的控制汇合到 BRAM 使能，数据延迟 8.111 ns，其中布线占 75.649%。该失败版本没有下载。

本版增加独立的 224×24 位归一化行缓存，卷积保留原有的 2048×128 位行缓存。RGB 归一化结果原来仅占低 24 位，高 104 位一直为零，写回工作区时显式零扩展到 128 位。额外逻辑存储为 5,376 位；模型、阈值、分辨率、计算与舍入规则不变。

当前证据：

- 117 张照片的完整 C 输出文件与已验收 V179 逐字节一致，包含分数、原尺寸掩膜和结果头；这是反复使用的开发集。
- 生成 RTL 明确包含两块独立 RAM。卷积行缓存的地址、使能和写数据直接连接卷积模块，不再通过预处理控制汇合。六种位宽、深度、写入对象、高位污染和控制共用破坏测试均被拒绝。
- HLS 估计使用 252 BRAM18、213 DSP、70,467 LUT、69,970 FF。与 V185 的 HLS 估计相比，增加一块 BRAM18，减少 482 LUT、201 FF；这些不是整机实际资源结果。
- HLS71 完整检测器的两次缩小配置 RTL 调用通过，分别为 547,158 和 547,166 周期。缩小配置不是实际 FPGA 图像吞吐测试。

一次复用 HLS70 综合结果的续跑方案失败在自动仿真封装链接阶段，尚未运行 RTL。已确认源文件、综合报告和全部综合 RTL 未改变，保留了失败记录；随后使用源文件相同的全新 HLS71 工程完成标准的 C 仿真、综合、RTL 联合仿真和 IP 导出流程。

当前正在进行 125 MHz 整机实现。只有整机时序、DRC、FIFO 总线偏斜、117 张直接数值核对及真实 HDMI 持续测速均通过，才能报告新的已验收速度。现有已验收速度仍为 V179 的 8.16955 次/秒。
