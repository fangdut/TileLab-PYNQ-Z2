# V190：相邻像素共享权重

实验把每个 DSP 的打包轴从两个输出通道改为两个相邻像素：仅对8个激活对进行打包，然后向16个输出通道广播。普通卷积仍使用128个共享乘法器，最近邻和深度卷积保持原精度。模型、阈值、输入尺寸不变。**尚无本版本整机布局布线及板端帧率验收。**

当前冻结源 `v170_hls76.cpp` 与 `texture_spatial_pair.cpp` 字节一致，SHA256 `775e6c5025bb12c6869a11d840444744cf863471e28dbcbd903800199ae7319f`。`PW_SPAN=16` 每批覆盖32个像素，减少窄特征图的空转；最近邻使用32槽，深度卷积使用16槽。生成 RTL 的32个累加器存储体写回间隔已检查为安全。

HLS75 是前一版每批32个像素对的试验：117张真实图片C评分和掩膜一致；实际MAC RTL642个输出包/895个停顿通过；完整AXI RTL连续两次启动13302个字一致。检测器本体实际综合42879 LUT、45007 FF、218 DSP、116 BRAM Tile，低于V188本体48726 LUT、57800 FF。**这一资源测量属于HLS75，不是HLS76的整机实现结果。**

HLS76的117张C评分及原尺寸掩膜逐值一致，HLS估计236 BRAM18、214 DSP。实际MAC RTL的642个输出包、853个停顿周期通过，完整AXI RTL两次启动13302个字一致；已导出IP并确认测试过的RTL/ROM未改变。完整HDMI系统100 MHz / ExploreArea实现进行中，尚无新版板端结果。26层普通卷积的静态MAC循环从1827584次变为913792次；计数排除流水启动、DDR等待、预处理、深度卷积、投影、最近邻和结果写回，不能当作帧率预测。

片上行缓存使用真双端口，供两个相邻像素读取。量化使用原16通道偏置/比例，每个1024位结果包包含两个像素，奇数宽度末尾只消费有效像素。权重布局、码本和DDR工作区布局沿用原格式。

已接受的持续视频基线仍为V179约8.17 FPS。V188的32输出通道方案虽通过C/完整RTL，但完整HDMI系统详细布局失败，未下载；V190须独立通过同样的完整系统和实板验收，不能沿用V188的失败或局部测试来声称已达标。
