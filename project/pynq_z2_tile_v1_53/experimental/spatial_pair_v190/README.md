# V190：相邻像素共享权重

当前候选为 **HLS79**，源SHA256 `490c8af82d9cab7be46b80709081d9c0f8effea84c28582d888a658e9a77d2e0`。采用精确模2^24累加和第四路DSP量化，数学依据见 [MOD24_PROOF.md](MOD24_PROOF.md)。159组标量测试、140955项检查通过，包含越过signed24范围的累加和极值偏置。117张完整回归评分及掩膜逐值一致；生成MAC RTL7种工况643个输出包、完整AXI RTL两次启动13302个字一致。本体实际40439 LUT / 43432 FF / 218 DSP / 132 BRAM36。完整HDMI整机仍待验证，无新版上板或FPS。HLS78因混合位宽条件表达式编译失败，已保留记录。

HLS77完整系统布局已失败：组合LUT54560 >53200、控制集合1113，未下载。HLS估计不能替代实际布局容量。

实验把每个 DSP 的打包轴从两个输出通道改为两个相邻像素：仅对8个激活对进行打包，然后向16个输出通道广播。普通卷积仍使用128个共享乘法器，最近邻和深度卷积保持原精度。模型、阈值、输入尺寸不变。**尚无本版本整机布局布线及板端帧率验收。**

HLS77历史冻结源为 `v170_hls77.cpp`，SHA256 `f8a7dabe4590b7a7e5404ecce24b84ce745adfd4572c3a4a2379d71466e934eb`。它把32个累加器存储体改用BRAM、每体16个有效槽，并把1024位结果FIFO缩为1项。117张C输出一致、生成RTL写回间隔安全，HLS估计268 BRAM18 / 214 DSP；实际检测器综合41809 LUT / 44872 FF / 217 DSP / 132 BRAM36；生成MAC RTL642个输出包、853个停顿周期通过，完整检测器AXI RTL连续两次启动13302个字一致。完整HDMI整机状态以报告为准，尚无本版板端FPS。

`PW_SPAN=16` 每批覆盖32个像素，减少窄特征图的空转；最近邻使用32次迭代但不访问累加器，深度卷积使用16槽。

HLS75 是前一版每批32个像素对的试验：117张真实图片C评分和掩膜一致；实际MAC RTL642个输出包/895个停顿通过；完整AXI RTL连续两次启动13302个字一致。检测器本体实际综合42879 LUT、45007 FF、218 DSP、116 BRAM Tile，低于V188本体48726 LUT、57800 FF。**这一资源测量属于HLS75，不是HLS76的整机实现结果。**

HLS76的117张C评分及原尺寸掩膜逐值一致。实际MAC RTL的642个输出包、853个停顿周期通过，完整AXI RTL两次启动13302个字一致；已导出IP并确认测试过的RTL/ROM未改变。但完整HDMI系统100 MHz / ExploreArea详细布局失败：组合后LUT54910 >53200，控制集合1108，未下载。它是当前BRAM映射实验的前一版，不能晋升。

26层普通卷积的静态MAC循环从1827584次变为913792次；计数排除流水启动、DDR等待、预处理、深度卷积、投影、最近邻和结果写回，不能当作帧率预测。

片上行缓存使用真双端口，供两个相邻像素读取。量化使用原16通道偏置/比例，每个1024位结果包包含两个像素，奇数宽度末尾只消费有效像素。权重布局、码本和DDR工作区布局沿用原格式。

已接受的持续视频基线仍为V179约8.17 FPS。V188的32输出通道方案虽通过C/完整RTL，但完整HDMI系统详细布局失败，未下载；V190须独立通过同样的完整系统和实板验收，不能沿用V188的失败或局部测试来声称已达标。
