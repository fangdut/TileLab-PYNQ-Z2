# V174 深度卷积吞吐优化

本目录为硬件实验源。最新已上板验收的版本仍是 HLS39 / V173 R2，HDMI 6.666 FPS。候选版本只有完成 RTL、整机资源/时序和实板回归后才能晋升。

## 当前候选 HLS46：直接缓存与单读行存储

`texture_direct_cache_s2p_dw.cpp` 冻结为 HLS46。117 张原始照片的 C 完整输出已与已验收 HLS39 逐字节一致；保留的九任务缩小夹具 C 仿真也通过，两次缩小配置RTL已通过。整机布线拥塞，已由本轮主动停止；现场保留，未上板。

点卷积直接读取既有 projection_cache，省去按输出组重复复制输入到 line；所有 stride=1/pad=0 的 1×1 点卷积都可批处理。深度卷积每步取一个列位置的三行，分三步累加，行存储改为 3×512 的简单双口 BRAM。保持原始位宽、取整和模型阈值。

当前模型普通卷积为 RGB 3×3 与 1×1 点卷积。为了覆盖保留测试夹具，也支持最多 48 个输入通道的小型非缓存 1×1 卷积。更大的非缓存卷积会被显式拒绝；重新换模型必须重新构建和核对形状。构建检查从二进制模型核对全部描述符，缓存最高地址为 8063，小于 8192。

HLS 估算为 248 BRAM18、208 DSP、76610 LUT、82442 FF；主乘加 II=1、深度28，累加读级1/写级26满足32次迭代间隔。这里的资源和周期不是整机时序或速度验收。

HLS43 的连续运行控制以及 HLS44 的逐行系数调整均通过117张 C 回归，但实际隔离综合 LUT 分别为40790、41457，比 HLS42 的40089更多，因此保留为未采用实验。HLS42 完整视频系统两种布局均失败，尚未上板。

## 第一轮候选结构（HLS42，布局失败）

`texture_bounded_dw.cpp`（冻结为 `../texture_v170/hls/frozen/v170_hls42.cpp`）保留原模型、阈值、整数精度与输出格式。

- 一个 `dot128` 物理阵列供普通卷积、深度卷积和近邻距离计算复用。深度 3×3 卷积按六个位置、三个位置分两步累加，移除原先独立的 `dw16` 实例。
- 行缓存改成三个 1024×128-bit 存储体；每体最多两个读请求，符合双口存储结构。逻辑缓存上限仍为 2048 个字，所有模型输入行宽不超过 224。
- 利用腾出的 DSP 把量化从四路提高到八路，每个像素由四次迭代改为两次。取整、饱和及 ReLU 保持原计算。
- 显式声明 32 次迭代的真实累加 RAW 依赖，生成 RTL 的读级 10、写级 41，写入在下一次同槽读取前完成。不能仅根据 C 仿真宣布流水线正确。

`test_parallel_dw.cpp` 直接包含实际候选源，用独立标量卷积核对边界、正负值（含 -128）、步长与环形行缓存。已核对 446430 个逻辑存储字、426 次 MAC 调用和 231936 个通道输出。该测试是离线检查，不代表硬件速度。

## 保留的失败

- HLS40 / `texture_parallel_dw.cpp`：尝试一步并行九个位置。C 117 张全值一致，但 HLS 为六个双口存储体估算 284 BRAM18，超过设备 280；流程在 RTL 和导出前拦截。未上板。
- HLS41 / `texture_two_step_dw.cpp`：资源估算降到 260 BRAM18、212 DSP，但旧的 `acc inter false` 导致读级 1、写级 42，而同槽间隔仅 32。RTL 仿真已实际报告此依赖冲突；在确认问题后终止该仿真，不计为通过，也未导出或上板。
- HLS42：有界地址和真实依赖约束；完整结果见后续 `reports/v174` 证据，未完成检查的阶段不能作为已通过。

`tools/fpga_texture_v170/check_mac_recurrence.py` 已加入构建前检查：对生成 RTL 的全部 16 个累加体核对读写级。HLS39、HLS42 静态通过，HLS41 被拒绝。这项检查补充完整 RTL 仿真，不能替代仿真与实板验证。

原始 MVTec Tile 117 张属于反复使用的公开开发集，不是独立盲测。所有运行检测计算仍安排在 PL，电脑 C++ 检查仅用于离线核对。

## HLS47：量化／投影 DSP 分配实验（未上板）

保持同一模型与输出格式，将量化由8路改回4路，投影由8路增至16路。117张完整C输出逐字节一致；16项与128项投影和的整数范围均安全。隔离串行综合用38574 LUT、43196 FF、217 DSP、122 BRAM；这不是整机资源或时序验收。完整HLS48采用逐字节相同的源，但在排队阶段取消，未启动；资源空闲后优先运行更小的HLS50架构。HLS47本身仅完成C和综合，没有RTL／IP导出或板上帧率。

## HLS49 / HLS50：降低物理实现压力的实验

HLS49 保持三步共享 DW，将量化改回4路、投影维持8路。117张完整C输出与HLS39逐字节一致；实际隔离串行综合为38594 LUT、43833 FF、211 DSP、122 BRAM。没有完整RTL、整机时序或板上FPS。

HLS50 / `texture_direct_cache_separate_dw.cpp` 回到HLS39的独立16路DW单元和九步累加，只加入直接PW缓存读取及显式真实累加依赖。117张完整C输出与HLS39逐字节一致；实际隔离串行综合34854 LUT、40539 FF、217 DSP、123.5 BRAM，完整同源HLS51正在运行RTL。缓存静态检查核对实际二进制模型，最大8063<8192；五项边界测试覆盖多行尾部、容量溢出和两种行缓存结构的拒绝条件。尚无RTL、整机或上板通过结论。
