# HFENet198：最终候选的完整整数硬件迁移

当前是候选源码，不能以离线结果代替上板验收。旧100MHz停驻工作站独立保留。

目标流程为：停住 → 送入原图 → FPGA检测和分割 → 保持结果 → 人工确认处置。
不再以10FPS作为本轮交付条件。没有实体相机、传送带和执行器时，处置只代表逻辑指令。

## 固定实现

- 复用RobotvisionLab HFENet epoch69；作者源码及MIT声明位于相邻`hfenet_v197/vendor`，没有重新训练。
- 本候选仅接收256×1408、RGB三通道相同的原始灰度扫描图。彩色输入由硬件拒绝。
- 71算子／72张量，16位激活与权重，48位MAC，32路共享计算阵列，DDR生命周期分配。
- 直方图均衡、Prewitt、卷积、动态InstanceNorm、残差、池化、插值、分割与判定均在PL。
- ARM仅实现网络、CRC、内存传输、启动及完成观测；电脑仅解码、传输、校验和显示。
- `native_wrapper.cpp`、离线参考及fixture生成器仅供验证，不是运行时检测后备。

## 验收顺序

1. `assemble_model.py`产生独立198 ABI模型，`validate_native.py`核对完整算子图。
2. `test_axi.py`核对完整RTL的两帧、72张量、掩膜清理及错误输入，采用随机权重算术fixture。
3. `export_hls.tcl`导出IP；`build_candidate.py`先绑定80图回归和RTL证据，再启动独立物理工程。
4. 整机综合容量、布局布线时序和DRC必须通过。HLS资源估计不代表能装入芯片或实际频率。
5. `build_software.py`从匹配XSA重建独立198固件。`program_board.py`仅做易失JTAG下载，不写Flash。
6. `accept_board.py --pilot`先核对一张正常／一张缺陷；随后不带pilot做全部80张掩膜逐值回归。
7. `station`沿用原停驻流程及放行联锁；仅在匹配新硬件实测通过后部署，未验收导入图只能待复核。

模型、照片、标注和激活栅格仅本地研究使用，不随公开源码包再分发。公开作者代码的许可不自动等于照片／权重再分发许可。
作者模型在作者数据上得到40/40缺陷检出、0/40正常图误报属于开发复现，不能宣称独立100%准确率。
扫描条带不等于完整实体瓷砖，任意彩绘、多材质和真实产线仍不在该证据范围。

最终提交包需绑定同一套源文件、模型摘要、BIT、XSA、ELF、真实板端结果与报告。
签署授权书、整机和开发板实拍仍须使用真实材料；本候选不会生成替代照片或代签。
