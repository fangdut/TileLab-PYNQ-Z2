# V207 匀速检测与异常复核

真实照片进入左侧检测区即从原生分辨率canvas截帧，经网口交给FPGA，瓷砖继续匀速前进。当前结果未报警且身份、核验与处置校验有效时自动通过；报警工件带着PL粗异常标记走到右侧复核区再停下，由人工复核。结果未及时返回时，同样在复核区停下等待。

默认截图点到复核区4秒、175像素/秒。本次实板测得截图到应用收到结果约2.48～2.56秒；它包括截图、解码、传输与应用开销，和历史约125ms的PL内核、约502ms的传图检测均值属于不同测量范围。界面可选3/4/6/8秒。

复核方式本次会话只确认一次，下一工件不清空；报警工件仍需逐件点击复核结论。未报警自动通过使用独立automatic_decision记录，disposition=automatic_pass、review=null，不生成伪造人工复核，不增加manual_reviews。人工冲突沿用原核验失效规则。

## 启动

先启动V202原工作站并完成本批参照核验。运行start_conveyor.ps1，-Config参数指向原工作站本次runtime中的station_config.json；可加-NoWindows只启动服务。

必要时脚本会调用upgrade_station.ps1：校验8793/8794进程和配置，保存检查点，迁移空闲或持有结果的电脑端工作站，重新核对板端身份和证据。它不下载BIT/ELF、不换模型，不允许迁移进行中的推理或处置。

- 操作页：http://127.0.0.1:8794/
- 显示器页：http://127.0.0.1:8794/display，负责截帧，保持打开。
- 原核验/审计页：http://127.0.0.1:8793/
- 默认01/02为正常开发样例、03/04为裂纹样例；界面不按预设编号产生判定。
- 启动队列后正常图无需操作。首次异常复核填演示代号并确认复核方式，之后只需点击结论。冲突或待定需说明。
- “本块后暂停”完成当前工件后不再进入下一块；关闭浏览器不代表服务停止，不另开板卡推理客户端。

## 实现与记录

server.py为HTTP接口，flow.py管理连续运动与当前工件；app.html/app.js为双屏界面。station_gateway.py与policy_station.py在原ClosedStation后端上增加明确的automatic_release操作。仍只有一个服务访问板卡，保持原BIT、ELF和冻结模型。

电脑负责模拟运动、canvas取帧、PNG解码/传输、显示与记录；ARM负责网络与校验，PL负责图像分析。截帧保留原生像素并与源照片逐像素核对，不把界面标记或背景送进检测。结果按工件、模型、启动编号、截图指纹与FPGA帧号绑定。

runtime中的events.jsonl和原station_records继续存储原始帧、板端结果与审计记录。自动通过和人工复核明确区分。录屏或进程重启后会开启新界面会话，复核确认需重新做一次。

## 验证

15项本地测试通过，覆盖错误帧、过期结果、缺失结果时停止、早到结果保持匀速、迟到结果恢复不跳跃、确认保留、自动通过不伪造人工意见，以及报警/失效核验拒绝自动通过。

accept_continuous.cjs为显式标注“自动回放、非人工”的实板验收。evidence_continuous/acceptance.json记录FPGA帧号12～15：两张正常图无停止采样、自动通过增加2次；人工复核计数仅因第一张裂纹的显式程序回放增加1次；下一张裂纹到右侧停下，勾选保留。正常图没有人工复核记录。

evidence_continuous/正常不停_异常复核_实板自动回放.mp4约39.93秒，为真实浏览器画面按实测时间戳原速编码，保留“非人工”字幕。正式真人演示不运行验收脚本。旧evidence和archive_stop_mode为历史停驻版，不作为本版效果。
