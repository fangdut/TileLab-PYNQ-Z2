# V202 换线后基线复测

保持V200100MHz检测核心与两参照固件。本轮不是算法或RTL修改。
所有测试顺序在plan.json中先冻结；失败不自动重试或重编程。
summary.json记录约310秒同一启动编号下的117图逐值复现、201次固定图硬件计算、22次接口闭环与100个完整周期。实时视频、全天长稳和未知花色准确率未验收。
CPU/ARM不承担视觉推理。脚本复核不是实际人工，放行/隔离没有机械执行器。
换线后本轮未复现POR，不意味着已唯一测定电气根因。之前失败见../v201。
10页报告已按原模板更新，实拍位置仍由参赛者补充。
run_retest_record.py和build_report_record.py保留本机验证/生成记录，含本机绝对路径；不是通用启动入口。工程包使用根目录启动检测.cmd。
