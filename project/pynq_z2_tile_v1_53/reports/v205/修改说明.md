# TileLab V205报告与仓库修订说明

本次把具身智能赛道截图作为内容参考，未把其推荐目录当作初级赛道强制格式。报告保留用户提供的官方Word五部分、页眉、页脚、字体样式、图表与编号，基于V203作增补，最终12页。

| 检查项 | 原材料情况 | 本次修改 |
|---|---|---|
| 结构与格式 | 已沿用官方五部分模板 | 保留，不改造成具身智能报告结构 |
| 选题与已有基础 | 有场景和算法来源，但取舍理由较分散 | 补应用问题、MobileNetV2选择依据和候选否决原因 |
| PC/PS/PL划分 | 已明确职责 | 补划分理由；如实写纯软件可实现同类功能，没有同口径收益实测 |
| AI PC要求 | 项目没有PC端推理模型 | 不新增不存在的PC模型；写明全部运行时视觉计算在PL |
| 协作接口 | 有请求、CRC与状态说明 | 补TCP端口、64字节头、RGB打包、序号关联及无跨设备对时的事实 |
| 复现步骤 | 启动说明和证据分散 | 报告增2.3.3；仓库补从工程包校验、环境、接线到核验与结果比对 |
| 指标一致性 | 指标正确但没有统一顶层入口 | 新增17项metrics.csv和离线汇总脚本，每项对应原始JSON字段 |
| 失败分析 | 已有记录，原因与决定不够集中 | 补跨材质误报、抬阈值漏检、HFENet候选、频率和POR的取舍 |
| GitHub首页 | 历史日志堆叠，含旧“当前V179” | 当前首页重写为评审入口，旧全文存README_HISTORY_V203.md |
| 默认分支 | main为旧V1.53.1 | 增加醒目当前分支入口，保留main历史内容 |
| 目录结构 | 既有脚本依赖工程原路径 | 不搬源代码；新增docs、metrics与实际路径映射 |

工程仍冻结V202，RTL、BIT、ELF、模型、阈值、启动器、V204海报和V203视频脚本均未修改，没有新的编译或上板验收。

复现保存边界：V202完整ZIP当前为本地交付，不是已经发布的GitHub下载资产。只clone仓库不能冒充取得该包；旧V179默认打包命令不能直接生成V202双参照闭环包。文档已明确区分工程包部署、存档指标离线复算和需适配的整套跨机器上板验收。没有宣称本轮完成任意新机器一键复现。

仍由参赛者补齐的内容：整机正面与斜45度真实照片、视频成片、签署和比赛提交。本次没有虚构这些材料。

真实性口径：117张为开发集，不是独立准确率；124.72ms是内核、501.79ms是传图加检测、1.220s含脚本复核等待。约8.02fps是固定帧内核微基准；没有实体机械产线、功耗或CPU/GPU加速比实测。换线后约310秒通过不证明全天长稳或唯一电气根因。
