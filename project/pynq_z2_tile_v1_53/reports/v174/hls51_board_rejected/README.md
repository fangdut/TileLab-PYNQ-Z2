# HLS51 实板候选：性能回退，未晋升

100 MHz 物理优化后时序通过，117 张公开开发照片的板端整数评分和掩膜全部精确一致。但固定帧为 7.443779 FPS，低于恢复原 HLS39 后同环境测得的 7.538978 FPS，下降约 1.26%。两次测试使用同一模型和同一输入 RGB CRC，不能把缩小 RTL 夹具的周期减少宣传为实板提速。

HDMI 供图程序因未发现外接720p屏幕而退出，本轮没有连续HDMI速度或准确率结论。恢复已验收HLS39后外接屏重新枚举；尚未证明丢屏的根因。所有失败、初次负时序、修复与下载身份均保留。当前板上恢复HLS39，新一轮V175改为采集/推理重叠，检测内核保持原样。
