# V166数据与验证范围

没有新增已获取的真实照片，没有新增真实同花色良品／裂纹配对，也没有训练分类模型。

174个算法开发用例来自`tools/reference_tile/fixtures.py`生成的6类程序纹理及采集扰动，人工线条带生成GT。这些是工程机制夹具，不能代表真实照片、独立实体砖或未暴露盲测。相同底图的不同扰动属于同一源组。

实际PYNQ-Z2回放使用原仓库MVTec数据中的17张裂纹图和33张正常图，经电脑HDMI、PL、DDR、以太网重新采集。原图及许可见[既有数据来源](DATA_PROVENANCE_V164.md)。`reports/v166/board_captures.zip`保存这50次已验证采集的原始PNG、PL掩码、硬件元数据及独立整数参考比较；照片和衍生图延续原数据CC BY-NC-SA 4.0归属与许可。它们是已有训练／开发图片，不得作为新独立准确率样本；同一张图的历史采集、当前采集和原始刺激不能合并计为不同实体砖。

没有相机拍摄实体瓷砖。板端图片为HDMI照片回放，既能验证传输与算术，也仍不能验证真实光学采集、固定照明、反光和现场生产变化。Windows输出链路存在颜色变化，独立整数参考始终比较实际回读RGB，不用原照片像素替代板端输入。

曾检索公开`ceramics-defects-detection`数据集（DOI10.17632/47x6jdbr5j.1）。作者注明1600张图片来自有限实体样本，当前未确认独立实体砖身份及逐花色空间配对，元数据API请求也返回HTTP403；没有下载、评估、上传或把它纳入任何分母。该来源只能作为后续调查线索，不能填补验收计数。

窗口算术仿真8192组、实板2048组重复3次是整数计算验证；重复执行不增加独立窗口数量，更不是图片或裂纹检出率。独立自检设计包含ROM和VIO，其资源和100MHz时序不代表完整视频参照算法的资源或帧率。

真实验收必须冻结实现和参数，按实体砖隔离标定与测试，保留逐图来源、完整原生输入、裂纹GT以及拒判。不允许用扩增图、合成裂纹、自对照、未匹配随机石纹参照或来源不明图片补足独立数量。
